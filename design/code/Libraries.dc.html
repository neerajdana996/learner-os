The move that makes all of this affordable
A concept is generated once and then read by ten learners across forty-five days. So the expensive, library-shaped work — tokenising code, laying out an equation, drawing a graph — happens in the generator worker, at generation time, and what lands in Postgres is already spans and coordinates. The frontend receives data and renders it with the plain React it already has.
This is what keeps loop.md §2’s “no UI library for the pilot” intact rather than quietly abandoned: the one package that must run in the browser is an editor, and it only loads on the one screen that has an editor on it.

shiki
4.4.3 · 603 KB npm
Backend
Tokenises code into coloured spans, once, in the worker. Real TextMate grammars, so the highlighting is right for every language a topic might use rather than right for JavaScript and wrong for Rust. We feed it our own five-colour theme from the design system. Alternative: prism-react-renderer (734 KB) does the same job but only in the browser — that is the wrong side of the wire here.

6.0.2 + lang packs
Frontend
lazy, one route
The one screen that genuinely needs an editor. Bracket matching, sane indentation, real undo, and — the reason it beats Monaco here — it works on a phone and it lets you turn autocomplete off. Monaco unpacks at 98 MB and its whole value proposition is IntelliSense, which on this screen hands the learner the answer. Imported behind React.lazy, so no other page pays for it.

when maths lands
renderToString at generation time gives HTML plus MathML. The browser needs the stylesheet and the fonts, not the library — about 25 KB of CSS against 4 MB of package. Listed here because it is the same pattern, not because the code category needs it.
diff
9.0.0 · 616 KB npm
Backend
Computes the before/after line pairs for codeDiff so the model does not have to emit two listings and get them consistent. Stored as the resolved diff; the client renders two coloured rows.
Sizes are npm unpacked package size — what pnpm install puts on disk, not what a browser downloads. They are the honest number for a backend dependency and a misleading one for a frontend dependency, so CodeMirror’s real cost gets measured in a bundle report before it ships, not guessed at here.
Running the learner’s code — zero packages
A sandboxed iframe, and a timeout
<iframe sandbox="allow-scripts"> on a blank srcdoc is a real origin boundary: no cookies, no DOM of ours, no network. Post the source in, post the case results back, kill it at two seconds. That is about eighty lines and no dependency.
What we are turning down, and why
quickjs-emscripten (2.4 MB) buys deterministic interpretation and a real instruction budget; pyodide buys Python at roughly 10 MB of WASM. Both are the right answer for a product that runs arbitrary code. Neither is worth it for a three-line debounce, and Python topics can grade server-side in the meantime.

@xyflow/react
12.11.6 · 1.2 MB npm
React Flow, for the systems category — drag a node onto a diagram, connect two services, and it is the only sensible way to build “where does the cache go”. It is a genuine frontend dependency with genuine weight, and it is the one place a canvas beats a form. Not for the concept map, which is hand-drawn SVG today and works.
mermaid
Rejected for the client. Renders a flow diagram from a text description, which is exactly what a model is good at emitting — so run it in the worker and store the SVG. Nobody should ship a diagram compiler to a learner’s phone to draw four boxes.
marked
dompurify
Rejected outright. Blocks are structured; prose needs bold, italic and inline code and nothing else. A markdown pipeline here buys an HTML sanitiser we would then have to be right about, in exchange for formatting nobody asked for.
One caveat worth putting in the commit message. loop.md §2 says “no UI library for the pilot”, and CodeMirror is a library that draws UI. The distinction being drawn is that these are content renderers, not a component kit — nothing here supplies a button, a layout or a theme. That is a real distinction and also a convenient one, so it belongs in front of a human rather than inside a diff.
