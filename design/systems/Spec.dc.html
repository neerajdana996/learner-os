The grader compares guarantees, not pictures
Assertion is pathExists · edgeAbsent · nodePresent — three predicates over the learner's graph, and solutions is an OR of AND-sets. Graph isomorphism would mark two correct answers wrong, and the scheduler would then reschedule a concept the learner already had. A wrong answer reports the first failed assertion, which is why the predicate list is short and readable rather than expressive.
No schema change — T-079 already covers it
concepts.domain takes 'systems', which is already in the enum. items.answer_kind takes 'graphBuild' and 'numeric' — and being text rather than an enum is exactly why this category needs no migration. That call is now paying for itself.
One new prompt file
llm/prompts/items/domains/systems.md, appended when the concept's domain is systems. It carries the format table from the first artboard, the node vocabulary the renderer knows how to draw, and the sentence a model will otherwise ignore: one answer block, so “draw it and justify it” is two items.
