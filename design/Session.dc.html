New concept · The dependency array
Your attempt
An effect fetches a user by id. What do you think happens if you leave the dependency array out entirely?
It probably runs once when the component loads.
A common way to read it
That’s the intuition almost everyone starts with, and it’s the opposite of what happens. No array at all means run after every render — so the fetch sets state, the state causes a render, the render fires the effect again. It’s an infinite loop, not a one-off.
How to hold it
The second argument answers one question: since the last render, did anything I care about change? Omit it and the answer is always yes. Pass [] and the answer is always no. Pass [userId] and it re-runs exactly when that id changes — which is what you almost always meant.
