The abstraction held
A blank in S = a1 − r and a blank in while (lo <= hi) are the same interaction, the same grader and the same fifteen seconds. Only the typesetting differs.
So this category adds no answer block at all — provided the code canvas ships cloze with a notation field rather than a block called clozeCode. That rename is free today and a migration plus a forked renderer in six weeks. It is the one decision on this page with a deadline.

What the generator is told to pick, and when
The concept is a condition
The result holds only when |r| < 1. Convergence criteria, domains, when a rule may be applied at all.
→ cloze over the condition
The concept is a manipulation
Multiply through, substitute, integrate by parts. There is one step everyone forgets.
→ cloze on that step
The concept is a value
Evaluate it. Nothing is being tested except whether the formula is actually available to you.
→ numeric, tolerance 0
The concept is a proof
The order is the argument. Get it wrong and you have assumed what you were proving.
→ orderLines, 4–6 steps
The concept is a fallacy
A derivation that reaches something false. Somewhere a step divided by zero and looked reasonable.
→ hotspot on the step
The concept is an intuition
“Why does the sum stay finite when you add infinitely many things?” No symbol answers that.
→ explain, plain text
